# Curriculum Vitae Website

This repository contains my personal Curriculum Vitae website, developed as part of the Hypermedia project.

# 1. Project Analysis

## 1.1. User Profile

The main user of the website is someone who is interested in learning about my academic and professional profile. Most likely, this person would work in the human resources department of a technology company and would be looking for a young candidate who can be trained and grow within the company.

Because these professionals review many CVs every day, the information on the website needs to be clear and concise. I have therefore prioritised information related to my technical skills, personal qualities and competencies.

An example user persona could be:

**Name:** Laura Martínez  
**Age:** 32  
**Profession:** Human resources professional at a technology company  
**Technical knowledge:** Intermediate  

**Goals:**
- Quickly find information about the candidate's education.
- See which programming languages and technologies the candidate knows.
- Review work experience and projects.
- Easily find contact details.

**Needs:**
- Clear and well-organised information.
- Good visual hierarchy.
- Short texts.
- Simple navigation.
- Professional design.

## 1.2. Information Architecture

The website has been designed as a **single-page website**, meaning that all the information in the CV is contained on one page. This structure allows the user to access all the information simply by scrolling vertically, without having to navigate between different pages.

The information is visually divided into **two main columns**. The left column contains the information that I consider quicker to consult: photograph, name, professional profile, contact information, technical skills and languages. This column is visually differentiated with a dark background and works as a quick-reference area.

The right column contains more general information. At the top, there is a short personal introduction that allows the user to quickly understand my profile. This is followed by my academic background, organised chronologically and showing the studies I have completed and some of the knowledge I have acquired. Directly below this section is my work experience. Finally, the website ends with a section dedicated to my strongest personal competencies.

The order of the sections was chosen so that the user moves from more general information to more specific information.

## 1.3. Visual Design

The visual design of the website is mainly based on a **neutral colour palette**, consisting of black, shades of grey and white. The aim is to achieve a professional and modern appearance without using too many colours that could distract the user from the main content.

The left column uses a black background with white or light grey text. This clearly separates the personal information from the rest of the CV. The main column mainly uses white and light grey backgrounds to make the text easier to read. Some sections, such as the profile and competencies, use dark grey to create contrast and visually separate the different parts of the page.

The chosen typography is a **sans-serif** font, specifically Arial, with Helvetica and sans-serif as alternatives. This typeface was selected because it is simple, easy to read on screen and consistent with the minimalist style of the project.

Regarding the layout, I chose an asymmetrical two-column composition. The left column takes up a smaller part of the screen and works as a sidebar, while the right column is wider and contains the main information.

Blocks, lines and different background colours are also used to separate the sections without introducing too many decorative elements. Headings use a larger font size, while secondary text uses grey tones to establish a clear visual hierarchy.
